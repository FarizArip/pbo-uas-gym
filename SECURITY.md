# Security Policy

## Supported Versions



| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

Jangan direport. Sesekali ingin direport, tolong jangan dicepukan ke dosen, melainkan hanya membuat issue baru (dan cek apakah issue tersebut pernah dicetuskan).
